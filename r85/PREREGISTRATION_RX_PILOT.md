## Family (G0)
Single stepping rotor with AZ input and output contacts, unknown bijective wiring W on 0..25, 97 letters in place, zero-based i. The state is s_i = d*floor(i/n) (mod 26). Encryption is c_i = W[(p_i+s_i) mod 26] - s_i (mod 26). Decryption uses invW: p_i = invW[(c_i+s_i) mod 26] - s_i (mod 26). The initial rotor phase is absorbed into W. **Scope is exactly n=1,2,3,4 and d=-1,+1, eight settings; all 26! W per setting searched heuristically.** This is distinct from fixed-alphabet periodic Vigenere; it does not test contact alphabets KRY/PAL/ABS, n>4, two rotors, extra transpositions, letter-triggered stepping, masked/non-English plaintext or multiple stages. Excludes NOTHING exactly.

Only ciphertext and generic model files reach the candidate generator. Each n/d setting gets 40 independent random starts, 10000 swap proposals/start, five geometric reheating cycles, greedy finishing, then up to three lexical refinements. Search score per plaintext = sum log P4 + 0.30 sum log P3 + 0.10 sum log P2. A TextBlob frequency-based DP word segmentation receives coefficient 0.70 in the final local refinement; rankings are by the displayed ngram score after that refinement.
