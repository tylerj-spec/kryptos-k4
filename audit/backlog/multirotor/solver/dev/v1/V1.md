## What happened
The annealing of all 48 plants finished. Then the main process loaded the R59 letter model, and `np.memmap` failed
with ENOMEM.
- The wrapper sets the per-process address-space limit (RLIMIT_AS) to the aggregate budget, 2,048 MiB.
- The 1.29 GB letter-model mapping did not fit beside the main process's existing address space.
- That space was the multiprocessing pool's threads and arenas; the resident memory was only 59 MB.
- `run_v1.py` held the annealing output in memory, so **nothing was written**.

The remaining version-1 budget (about 462 s CPU) cannot repeat the panel run at the declared effort. **Version 1
therefore ends INCOMPLETE with no recovery evidence.** It counts as one of the work order's three versions.

## What carries over
Nothing about solver power was learned. Version 2 therefore reruns version 1's solver and parameters **unchanged**,
with the stages in separate jobs:
- the letter-model load is checked first, in a fresh process;
- the annealing output is written to disk before any scoring.

The code moved from `rx2o/` to `audit/backlog/multirotor/solver/`, because the guardrail check refuses a new
top-level directory. The only code changes are root paths.
