# R40G — independent Gromark IC statistical audit

This research is **not Claude's R40 one-free-plaintext-alphabet experiment**. It was originally developed in an earlier branch as R40 and has been relocated without changing the original tested hypotheses. The original preregistration commits remain in git history.

- Original blind R39 key ranking: all 100,000 five-digit Gromark primers.
- Mathematical quotient: 25,024 unit-multiplication classes (not independent cipher solutions).
- Histogram-preserving null experiment: 716 of 1,000 shuffled 97-character K4 ciphertexts score at least as highly as the original, after maximizing over the entire primer family.
- Post-freeze check: 39 Gromark primers are consistent with the two publicly known K4 phrases when both alphabets are free; zero were in the top 1,000 blind IC keys; this is **crib-assisted validation only**, not plaintext discovery.
- Exact source: `null_gate.cpp` (no known plaintext) and `postfreeze_oracle.py` (known letters used ONLY after the R39 freeze).
- Raw 1,000-null outputs are generated by the read-only PR CI workflow, which checks exact counts and attaches output artifacts. No CI job pushes or changes historical frozen runs.
- The merged main ledger entry **L137** independently reports Claude's replay and review of these results.

Always begin a new candidate search from original K4 ciphertext, freeze candidate outputs before comparing to known plaintext, and require planted-message recovery. This audit provides **no verified K4 solution**.
