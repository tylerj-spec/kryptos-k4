# Kryptos K4 — Strict-blind research

This repository preserves the Round 33 research code, historical source data, frozen results, reproducibility scripts, and cumulative ledger.

**Research status:** no verified K4 solution. All new blind K4 solvers operate only on the original 97-letter ciphertext; known plaintext clues are checked separately, after output has been frozen. Older crib-assisted investigations must never be mislabeled as blind decryptions.

Start at [HANDOFF.md](HANDOFF.md), [LEDGER.md](LEDGER.md), and [r33/README_START_HERE.md](r33/README_START_HERE.md). Run `bash verify_all.sh` for an offline audit. The package contains the original Round 32 handoff as a historical artifact.

No external verifier submissions are authorized by this repository.
